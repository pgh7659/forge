# Prompts

Reusable agent prompts and operating playbooks live here.

Prompts should state expected context, allowed actions, and stop conditions.

- `hermes-assistant-soul.md` is the public, non-secret identity template for
  the Discord-connected personal assistant and gateway profile.

Forge does not define an initial Hermes coder, reviewer, or operations profile.
Engineering uses the Forge Codex dispatcher; operations use deterministic,
approval-gated runbooks.
